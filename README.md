# PARTA Practice

Пиратская интерактивная диагностика для начальной школы (версия v47).

## Публикация сайта

1. Распакуйте архив `PARTA_practice_lossless.zip` из ChatGPT.
2. Загрузите содержимое распакованной папки в корень репозитория через **Add file → Upload files**. Должны появиться `index.html` и папка `assets/`.
3. В **Settings → Pages** выберите **Deploy from a branch**, ветку **main** и каталог **/(root)**.
4. Откройте https://kitrizaro.github.io/parta-practice/ после успешной сборки.

### Проверка неизменности

В этой сборке из оригинального HTML v47 только извлечены встроенные картинки в отдельные файлы. **Картинки не пересжаты**. Обратное восстановление ссылок даёт побайтово исходный HTML. SHA-256 оригинала: `1455308263c105e4309d8fedd60fa56e55f4784ceef4e6e29443a9f09eee2f84`.

Обработка изображений и логика игры не изменены. Прогресс сохраняется только локально в браузере.
