# ПАРТА · версия 19

Готовая статическая сборка для GitHub Pages.

1. Распакуйте архив.
2. Загрузите всё его содержимое в корень репозитория, сохранив папку `assets`.
3. В настройках GitHub Pages выберите публикацию из корня нужной ветки.

Точка входа — `index.html`. Установка зависимостей и сборка не нужны.

Изменения версии 19: увеличены картинки и места для расстановки в редакторе команд. При первом открытии новой сборки все карты начинают с нуля. Обновление текущей вкладки сохраняет её прохождение. Остальные задания не изменены.

Для запуска одним файлом без сервера используйте отдельно выданный `PARTA_1-6_Final_19.html`.
